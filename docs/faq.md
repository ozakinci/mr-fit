# FAQ

**Does my progress save?**
Yes, automatically, in your browser. You don't need to do anything.

**What's the difference between the big button and the exercise buttons?**
The big **Work Out!** button gives every exercise (Push, Pull, Legs, Core) 1 rep at the same time. Each exercise's own button does a full set of just that exercise in one click — more reps at once, but only for that one exercise.

**Why is the Pull set so much smaller than the others (+5 vs +10, +12, +15)?**
Pull-ups are just harder to do a lot of in one set than push-ups, squats, or core work, so a Pull set is smaller. It still counts the same toward your muscle per rep.

**What is muscle, exactly?**
It's your overall progress stat — every rep you complete, from any exercise, adds to it. There's nothing to buy or spend it on right now; it's simply a record of the work you've done.

**Can I get tired or overdo it?**
Not yet — there's no fatigue or rest requirement in the game right now, so you can work out as much as you like without a penalty. A fatigue system is planned for a future update.

**What happens if I close the tab / turn off my computer?**
Nothing bad — your progress is saved. Reps and muscle pick up right where you left off next time you open the game.

**Is there an ending?**
Not right now — it's an ongoing loop of building reps and muscle. Check the project's roadmap if you're curious what's planned next.

**I think I found a bug. Where do I report it?**
Open an issue on the project's GitHub repository, if it's hosted publicly, or contact whoever gave you the game.

**Can I move my progress to a different browser or computer?**
Not yet — save data lives in your current browser only.
